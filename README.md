# GITS STORE® — Digital Store
Website statis untuk etalase produk digital, dengan gaya visual cinematic hitam-merah dan font signature yang dipertahankan.

## File
- `index.html`: halaman utama dan katalog produk
- `project.html`: detail produk
- `admin.html`: admin lokal untuk mengelola katalog
- `style.css`: desain responsif dan animasi
- `app.js`: interaksi katalog, filter, tema, dan formulir

## Deploy
Upload semua file ke GitHub lalu import repository ke Vercel. Tidak perlu build command; gunakan root directory.

## Catatan
Admin dan formulir saat ini menyimpan data di localStorage browser, bukan database online. Perubahan tidak otomatis tersinkron ke perangkat/pengunjung lain. Harga yang ditampilkan adalah harga awal contoh dan perlu dikonfirmasi sebelum transaksi. Tautan pemesanan/WhatsApp belum terhubung ke nomor toko.
