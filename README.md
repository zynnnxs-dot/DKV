# ARSHAVIN® Design Studio Portfolio
- `index.html`: landing page, galeri/filter, about, formulir request
- `project.html`: detail setiap proyek
- `admin.html`: admin lokal untuk tambah/edit/hapus karya
- `style.css`: styling responsif, tema terang/gelap, animasi
- `app.js`: interaksi dan data proyek contoh

## Deploy
Upload semua file ke repository GitHub lalu import repository ke Vercel. Tidak membutuhkan build command; output directory bisa dibiarkan default/root.

## Catatan admin
Admin ini menggunakan `localStorage`, jadi hanya untuk demo lokal/browser yang sama. Data tidak tersinkron ke pengunjung lain. Untuk admin online yang aman, dibutuhkan backend/database dan autentikasi.
